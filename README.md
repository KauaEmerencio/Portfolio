# Portfólio — Kauã Lisboa Emerencio

Este repositório contém o código-fonte do meu **portfólio pessoal**, desenvolvido para apresentar meus projetos, habilidades e evolução como desenvolvedor, reunindo trabalhos acadêmicos e iniciativas próprias.

🔗 **Acesse o portfólio online:**  
https://kauaemerencio.github.io/Portfolio/

---

## Sobre o Portfólio

O portfólio foi criado com o objetivo de centralizar meus principais projetos e servir como uma vitrine do meu aprendizado em **desenvolvimento web**. Nele, apresento aplicações desenvolvidas ao longo da graduação e estudos práticos, sempre buscando organização, clareza e boa experiência para o usuário.

A proposta é oferecer uma visão direta sobre meu perfil técnico, minha forma de desenvolver soluções e minha evolução na área de tecnologia.

---

## Desenvolvimento

O desenvolvimento do portfólio foi feito de forma incremental, com foco em:

- Estrutura de código organizada  
- Interface limpa e moderna  
- Navegação simples e intuitiva  
- Layout responsivo para diferentes dispositivos  

Cada seção do site foi pensada para facilitar a visualização dos projetos e permitir futuras atualizações conforme novos trabalhos forem sendo desenvolvidos.

---

## Tecnologias Utilizadas

As principais tecnologias utilizadas foram:

- **HTML5** — estrutura das páginas  
- **CSS3** — estilização e responsividade  
- **JavaScript** — interatividade e lógica  
- **Git e GitHub** — versionamento de código  
- **GitHub Pages** — publicação do portfólio  

Essas tecnologias permitem um projeto leve, funcional e fácil de manter.
